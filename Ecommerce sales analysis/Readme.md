# 🛒 E-Commerce Data Analytics Project

> **An End-to-End Data Analytics Project using Python, SQL, and Power BI**

---

## 📖 Project Overview

This project presents an end-to-end analysis of an E-Commerce dataset. It covers the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and an interactive Power BI dashboard.

The objective is to extract meaningful business insights from raw data and demonstrate practical data analytics skills.

- Checked missing values
- Removed duplicate records
- Converted date columns into datetime format
